# Независимый разбор UI и UX — 2026-10-11

Проверена версия 0.3.1, коммит `d5129ba6b834aa98b77d09859631458382080282`. Это экспертный разбор первого использования, а не исследование с независимыми пользователями. Код плагина в рамках проверки не менялся.

## Основание и пределы

Проверены актуальные исходники admin PHP/JS/CSS, русские тексты, список заявок и генерация HTML пакета. Визуально просмотрены реальные полноразмерные русские скриншоты 1280 px и 390 px из [последнего VPS-прогона](https://github.com/DanilaH/forminator-file-packs/actions/runs/38034239771); архив доказательств проверен на CRC. Проверены результаты 15 UI-сценариев и сами браузерные сценарии. Новый живой прогон WordPress в этой проверке не проводился. Нельзя утверждать, что новый пользователь успешно справился: предыдущая автоматизация знает ID элементов и нужную форму заранее.

## Вывод

На уже открытой странице основной экспорт устроен понятно: выбрать форму, отметить заявки, проверить состав, скачать ZIP. Не нужны настройки шаблонов или технические знания. Повторное использование должно быть проще первого; это экспертная оценка, а не измеренный результат.

Однако назвать UX полностью готовым для новичка пока нельзя. Проблемы находятся на входе в сценарий, в объяснении результата и при восстановлении после ошибки. Полный тур с модальными окнами не нужен. Нужны короткие встроенные пояснения и конкретные действия в проблемных состояниях.

## Что уже хорошо

- Три пронумерованных шага; следующие разделы появляются по мере продвижения.
- Привычные элементы WordPress; видимые подписи и счётчик выбранных заявок.
- «Выбрать эту страницу» не обещает экспорт всех результатов; выбор сохраняется между страницами.
- Оригиналы остаются без изменений; это объяснено во вступлении.
- Неполный архив требует явного согласия и получает отдельное сообщение о результате.
- Есть проверка актуальности состава перед сборкой и понятный отказ при изменении данных.
- Предпросмотр получает фокус; статус использует live region. Предыдущие тесты подтвердили конкретные клавиатурные действия, а не полное соответствие требованиям доступности.
- На реальном скриншоте 390 px нет горизонтального переполнения; дата заявки остаётся видимой.

## Важная визуальная оговорка

В реальных скриншотах над плагином находится крупный англоязычный запрос оценки Forminator. На мобильном он занимает значительную часть первого экрана. Это уведомление зависимости, а не собственный UI File Packs. Его нужно учитывать при оценке первого экрана; нельзя автоматически скрывать чужие уведомления или приписывать их нашему переводу. Формат `mm/dd/yyyy` в нативном поле даты зависит от браузера/локали и сам по себе не доказывает дефект русского каталога.

## Предлагаемый онбординг

Достаточна компактная постоянная подсказка на странице:

> Выберите форму → отметьте заявки → проверьте состав → скачайте ZIP. Распакуйте архив и откройте index.html для просмотра заявок и файлов. Исходные данные не изменяются. Поддерживаются вложения, сохранённые локально на сайте.

Рядом с периодом: «Период необязателен. Без дат показаны все сохранённые заявки, по 25 на странице». Рядом с выбором: «Выбор сохраняется при переходе между страницами». В результате отдельно объяснить HTML, CSV и JSON человеческими словами. Дополнительную справку можно раскрывать по ссылке «Как пользоваться».

Не нужны обязательный многошаговый мастер, видео, демонстрационные заявки в пользовательской базе, модальные подсказки на каждом клике или отдельная система отслеживания прохождения онбординга.

## Проверка после доработок

1. После установки найти экспорт через строку плагина и выполнить первый пакет без README.
2. Проверить 1 форму / много форм, 0 заявок / пустой поиск / пустой период; в каждом случае понятен следующий шаг.
3. Выбрать заявки на двух страницах, увидеть весь выбор и проверить его перед скачиванием.
4. Изменить период после выбора: интерфейс точно объясняет, что произошло с выбором.
5. На 390 и 320 px нажать скачивание внизу: ожидание и ошибка видны без поиска сообщения в начале страницы; клавиатурный фокус не теряется при скрытии раздела.
6. Пройти отсутствие ZIP-модуля, недоступное private storage, сетевой сбой, истечение сессии, изменившиеся источники и неполный пакет. Следующее действие доступно и понятно.
7. После загрузки понять без документации, что распаковать и какой файл открыть.
8. Если доступен новый пользователь, дать эти задачи без подсказок и наблюдать реальные затруднения. Автоматизированный проход не заменяет такую проверку.
